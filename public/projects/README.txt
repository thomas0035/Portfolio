Drop project screenshots here, then list them in src/data/profile.ts under the
project's `images` array, e.g.

  images: [
    { src: '/projects/chorewars-1.png', alt: 'ChoreWars league table' },
    { src: '/projects/chorewars-2.png', alt: 'Area rotation view' },
  ],

PNG or JPG, ideally under 400 KB each. Landscape ~1600x1000 for web apps,
portrait phone screenshots (~1080x2400) for CardWallet are fine too.
